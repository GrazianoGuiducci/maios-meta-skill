# Examples: software documentation, a museum, research and a community project

## Planning software: documentation for the new offline workflow

Illustrative case. A planning tool gains an offline workflow, but its public guide still assumes a permanent connection. The activity reads the owning implementation and release notes, distinguishes the released workflow from an unfinished synchronisation proposal, and follows the user path through the feature page, guide and example file. It updates the entrusted documentation in both languages and checks that the example delivered is the current one. Learning: later comparisons must follow the workflow's conditions of use, even when the feature name stays unchanged.

## Museum: a workshop guide for different sensory needs

Illustrative case. A museum has improved how facilitators adapt a workshop to different sensory needs. A celebratory page alone would not transfer that ability. The activity forms a usable guide with the decisions facilitators make, accessible materials, three situations and a first assignment. Participant records stay private. The owner still describes the method as developing; the public introduction preserves that state. Learning: future resources must carry the practical choice-making knowledge as well as an attractive description.

## Research: a public explanation after a model is revised

Illustrative case. A group publishes a revised model while a public explainer still presents an earlier hypothesis as settled. The activity reads the paper and the group's qualified account, then revises the affected explanation and teaching example. It preserves what remains unresolved and routes a separately owned teaching assistant's source update through its actual owner. Learning: updating the visible page alone does not change the material that another consumer receives. A quiet later run keeps the still-correct explanation.

## Community project: a new guide changes the AI activity’s instructions

Illustrative case. A community project repeatedly receives reports that its website is unchanged, although a source guide has acquired a better operating method. The activity recognises that it was comparing versions and page text while missing the practical knowledge in the guide. It changes its source entry and continuation instructions within the entrusted range. If this changes the scheduler's prompt, it preserves the complete private configuration before and after and reads back the real job. Learning: improve the point where knowledge failed to participate, rather than creating a second recurring audit.
