# Eight additional MAIOS resources

This source branch prepares eight new resource kits alongside the 25 existing ones. New kits declare version 0.1.0 and prepared state. English methods and Italian counterparts carry the same decision relations and developed cases.

| Competence | Work it makes possible |
| --- | --- |
| [D-ND Learn From Demonstration](../skills/dnd-learn-from-demonstration/README.md) | Learn the decisions and conditions behind an example and apply them in a different case. |
| [Situated Possibility Formation](../skills/situated-possibility-formation/README.md) | Develop useful questions, capabilities and directions from a changing project field. |
| [Semantic Relational Comprehension](../skills/semantic-relational-comprehension/README.md) | Understand source, reasons and observation conditions so a method can be adapted faithfully. |
| [Cognitive Delegation Manager](../skills/cognitive-delegation-manager/README.md) | Compose contributions from assistants and reconcile their work and learning. |
| [Transfer Kernel Potential](../skills/transfer-kernel-potential/README.md) | Transfer a capability's operating and generative knowledge through the recipient's own means. |
| [Resource Need Formation](../skills/resource-need-formation/README.md) | Form the needed resource function, reason, substitutes, amount and timing before choosing a carrier. |
| [Authorial Source Discrimination](../skills/authorial-source-discrimination/README.md) | Preserve authorial meaning through adaptation and learn from consequential corrections. |
| [Concept-to-Media Formation](../skills/concept-to-media-formation/README.md) | Develop a shared source relation into a coherent editorial media family. |

The competence names preserve their source identities. Localized titles explain their use. Each folder includes the operating method, practical guide, worked examples, a complete chat starter and installation instructions. The starter contains the method, operating knowledge and cases so it can be used without private sources. The downloadable archive includes Apache-2.0 licensing and attribution.

The methods are public derivations of competences developed through MAIOS work across different owners. Private traces, individual writing corpora, account state and original node authority are not dependencies of these kits. The new cases are illustrative and do not claim observed adoption or behavioral assimilation.

Repository source, downloadable archive, website, assistant context, installation and use retain their own identities. The prepared edition supplies reviewable material; a later publication or receiving exercise has its own selected effect and evidence. Existing installations and knowledge evolved by their users should be preserved when considering an update.
