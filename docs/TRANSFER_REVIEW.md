# Native-to-public competence transfer review

The public collection contains adaptations of competences developed through
MAIOS work. A review on 20 October 2026 identified differences that must be
reconciled before claiming that the collection transfers the full native
capabilities. The current packages remain public edition 0.2.0.

The English operating bodies are present. However, the 24 example files after
Meta-Activity use brief catalogue examples in place of the more developed
Italian cases. In Proto Movimento and Kernel Plugin Incarnation, that
reduction loses the situation, causal distinction and corrective choice that
make the example useful. Having an example file in both languages does not
establish that they teach the same method.

Some adaptations also have a narrower operating scope. Material Work
Continuity supplies a textual method, while its native competence also has a
deterministic instrument and schema. Kernel Plugin Incarnation preserves core
distinctions but does not include all the operational knowledge of its native
plugin-field guides. Those differences need either a usable transfer or a
precise statement of the public contribution.

Other relations are preserved in the examined bodies, including attribution,
decision reasons, situated composition, correction within work and learning
return. The review does not treat every shortened method as a failure.
Historical procedures in native sources also need to be understood through
the current operating relation rather than copied as compulsory stages.

The review compares the actual knowledge a recipient receives with the
qualified source and relevant guides. File identity, language checks and
website delivery remain evidence of those properties. They do not prove full
functional transfer or later assimilation. The queued editorial series is
held during reconciliation; no future publication is asserted here.

The existing folder identifiers are early distribution identifiers. Resource
headings preserve source competence names, which remain the same in both
languages. Changing an identifier alone would not repair an operating gap.

This note records the current review status. It does not publish replacement
methods, install a tool, migrate a scheduled activity or establish recipient
behavior. Corrections follow the method, guide, examples, starter and any
dependent package, page or editorial text whose use changes.
