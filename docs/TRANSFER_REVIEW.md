# Native-to-public transfer: correction in edition 0.3.0

The selected work is to make the native competences publicly usable while preserving their portable functions. Private case identities, credentials, local configuration and another operator's effect authority are removed; the knowledge and means needed to perform the work are retained.

## What went wrong in 0.2.0

The collection had English operating bodies and bilingual presentations, but several useful source relations were compressed too far. The 24 English example files after Meta-Activity had been generated from short catalogue phrases instead of the developed Italian cases. Some source guides and portable tools had not reached the public recipient. Distribution aliases also obscured the native competence identities.

Language, package identity and website checks verified those technical properties. They did not establish that every useful function had been transferred. Describing a narrower public scope would not complete the selected all-functions transfer.

## What the reconstructed kits contain

All 25 kits retain an English operating entry and an Italian counterpart. Each now has practical operating knowledge in both languages, reachable from the entry, use guide and website. Complete chat starters include that knowledge, developed examples and the runtime source files supplied with executable functions. A recipient can inspect conditions, choices and mechanisms rather than receiving a catalogue description alone.

The 72 developed cases for resources 01-24 preserve the situation, causal distinction and corrective choice of their Italian counterparts. The Meta-Activity kit retains its 18 contexts and gains the receiving-context continuity method. Cases illustrate possible use; they are not invented reports of customer deployments.

Portable tools are included where the native function uses them:

- **Material Work Continuity:** deterministic event reducer, state/event schema, six-event worked ledger, CLI instructions and portable source tests.
- **Meta_Skill:** host-selected, read-only source/competence orientation, example manifest and retrieval tests.
- **Incarnate Neutral Kernel Node:** read-only source/receiver inspection parameterized by an explicit public mapping, plus a test with temporary repositories. Private node mappings and installation fixtures are excluded.

Practical guides also restore receiver migration, accumulated operating guides, relational competence participation, cross-receiver composition, human comprehension, reciprocal UI construction, plugin-field operation, autological maintenance and generative formation through recipient experience. Historical procedures are understood through the current method rather than copied as compulsory semantic gates.

## Identity and language

Operating folders and `name` metadata use the native competence entry names. Original readable competence names remain identical across languages. Functional descriptions, guides and cases are localized. Stable website resource IDs are distribution coordinates, separate from competence names. [IDENTITIES.json](IDENTITIES.json) records their correspondence. Former distribution folders contain English links to the current kits; historical file versions remain available through Git history.

## Checks and their meaning

Portable tool tests exercise event integrity, source/projection separation, correction without effect erasure, source changes, retrieval gaps, scoped repository changes and preserved pending integration. Package checks compare delivered files with the selected source snapshot. Page checks compare language, native identity, links, examples, operating knowledge and starters with that source.

These checks concern the function or delivery actually exercised. They do not authenticate an arbitrary external source, establish another host's permissions or prove general assimilation in an unknown recipient. Later non-identical use can improve the public competence and its transfer method. The selected editorial series derives from the reconstructed kits; completed publications retain their original effect history.
