# Form Public Meta-Skill Resources

Trasformare una competenza interna in una risorsa pubblica

Collega il saper fare trasferibile a guida, primo uso, repository, pagina e derivazioni editoriali.

Forma una risorsa utilizzabile fuori dal contesto d’origine, conservando il metodo e rendendo chiaro come iniziare nella propria AI.

Quando un team vuole condividere un metodo o una skill maturati nel lavoro e renderli utili anche ad altri.

## Adattare il metodo al proprio lavoro e ambiente

Ricerca, educazione, software, servizi e progetti culturali portano fonti e scelte diverse. Porta lavoro, sapere esistente e mezzi realmente disponibili. Il caso della biblioteca insegna relazioni adattabili; non prescrive il tuo progetto.

Una conversazione usa l’avvio completo e restituisce una guida da salvare. Un sistema con accesso ai file conserva il kit intero e lo collega attraverso l’ingresso nativo dell’ambiente. Un kernel esistente compone il contributo pertinente con le proprie competenze e l’apprendimento locale.

## Primo uso

Leggi SKILL_IT.md e GUIDA_OPERATIVA_IT.md. Allega in chat l’intero AVVIO_CHAT_IT.txt e descrivi il tuo incarico. L’avvio include metodo, sapere pratico e 5 esempi sviluppati.

## File ed edizione

Edizione pubblica 0.3.5. Inglese principale, con corrispondenti file italiani. Leggi INSTALL_IT.md per l’installazione nel progetto. Il metodo si usa autonomamente o con un kernel. Esempi ed esplorazione sul sito sono illustrativi.
