# UX-AI Kernel Design

## Form a reciprocal, simultaneous working surface

The person and the AI can act in the same field on the same object. The person orients, contributes and corrects; the system exposes information, changes and proposals while human work continues. Preserve the draft, selection, focus and reasons when a new observation arrives. Timing, hierarchy and form belong to the relation, rather than an after-the-fact decoration. A significant uncertainty must be perceivable where it changes a decision.

Preserve the receiving person's selected communication contract. If they use a competence footer as a continuity surface, retain its presence and adapt density: actual contribution, decisive consequence and useful continuation. This does not impose that footer on unrelated recipients or prove hidden participation. Put decision-changing information in the answer where it is used. Human silence does not establish understanding. If a reformulation exposes a missing premise, return to the object and reform the work.

## Construct the medium from the relation it must express

Understand the domain object, relevant states, changes, choices and intervention points. Choose conversation, a document, a table, a static view, an interactive scene or another available medium according to what must become understandable. Space, time, dependencies and alternatives may benefit from interaction or motion; no fixed maturity ladder requires it. Devices, environment, noise and physical conditions can change reception without prescribing a technology. Multiperceptual forms remain possibilities to construct with actual means.

Use the actual visual-design and code-construction knowledge available to build the form. From a demonstration, learn hierarchy, rhythm, camera, transition, materiality, typography and perceptual continuity with their conditions. Separate reusable grammar from brand, content and assets. Build original code for the current object rather than treating an external demo as the capability. Reusable tools may help without becoming a compulsory stack.

## Keep meaning, rendering and intervention connected

Expose shared semantic state to the system and to the person. A screenshot alone cannot recover an unexposed selection, temporal lens or transient target. Distinguish a temporary pointer from a persistent selection. Bind values and events so a human change reaches the working state and a system change becomes perceivable. Preserve orientation through transitions; moving geometry should reveal a relationship or state change.

Choose among retaining, adapting or rebuilding a form through the relations it can actually express. A preferred projection cannot manufacture a missing capability. Search for, compose or construct that capability when needed. Observe the rendered outcome and reachable state at meaningful moments; separate a fixture from the evaluator deciding what it can express. Compare human intervention and programmatic change, including focus and accessibility. Keep original editable sources. A weak result can require a code correction, a different expressive grammar or a reformulated question. Return that cause to the competence that must build or communicate differently next time.
