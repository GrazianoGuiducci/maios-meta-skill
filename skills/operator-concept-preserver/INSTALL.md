# Install Operator Concept Preserver in Codex

This kit is version 0.3.2. Keep the whole `operator-concept-preserver` folder together.

1. Extract the downloaded ZIP.
2. Copy `operator-concept-preserver` into your project's `.agents/skills/` directory. The entry is `.agents/skills/operator-concept-preserver/SKILL.md`. Preserve any existing folder rather than overwriting it.
3. Open Codex in that project and invoke `$operator-concept-preserver` with a concrete intent and relevant sources. Restart the session if the entry does not appear.

Ask for Italian output to work in Italian; the installed entry remains English and SKILL_IT.md is available. Read OPERATING_GUIDE.md and observe first use with your actual tools. Appearance in the selector, useful work and later learning are distinct observations. Compare future updates with local knowledge before integrating them.
