# Onto-Skill

Trasformare le correzioni dell’autore in criteri per l’AI

Distingui una preferenza locale da un principio riusabile e cambia il metodo che guiderà il prossimo lavoro.

Riconosce un principio trasferibile nel contributo dell’autore e lo rende operante nella competenza e nell’abilità pertinenti.

Quando una correzione importante resta nella conversazione e deve cambiare il modo in cui lavora la tua AI.

## Primo uso

Read SKILL_IT.md and GUIDA_OPERATIVA_IT.md. Allega in chat l’intero AVVIO_CHAT_IT.txt e descrivi il tuo incarico. L’avvio include metodo, sapere pratico e tre esempi sviluppati.

## File ed edizione

Edizione pubblica 0.1.1. Inglese principale, con corrispondenti file italiani. Leggi INSTALL_IT.md per l’installazione nel progetto. Il metodo si usa autonomamente o con un kernel. Esempi ed esplorazione sul sito sono illustrativi.
