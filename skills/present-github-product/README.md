# Present GitHub Product

Present a GitHub product through the work it enables

Connect README, metadata, evidence and first use so newcomers can understand and begin.

Turns a repository into a coherent product presentation with real capabilities, pertinent evidence and a usable first step.

When a README is accurate but newcomers cannot understand the product, its relevance to their work or how to begin.

## Adapt the presentation to your product

Preserve the relationship between product identity, the recipient’s work, capability supported by sources and the first available action. Sector, maturity, audience and evidence form vary.

Bring README, project instructions, an actual use case, installation, state and proof. A repository can carry software, an educational method or research; the form follows what the reader can do now.

## First use

Read SKILL.md and OPERATING_GUIDE.md. Attach the whole START_CHAT_EN.txt in a chat and describe your actual assignment. The starter includes method, practical knowledge and 3 worked examples.

## Files and edition

Public edition 0.1.0. English is primary; Italian counterparts are included. Read INSTALL.md for project installation. The method is usable independently or with a kernel. The examples and the website exploration are illustrative.
