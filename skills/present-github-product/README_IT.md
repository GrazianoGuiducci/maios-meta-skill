# Present GitHub Product

Presentare un prodotto GitHub dal lavoro che permette di fare

Collega README, metadati, prove e primo uso, così chi arriva può capire e iniziare.

Trasforma una repository in una presentazione coerente del prodotto, con capacità reali, prove pertinenti e un primo passo utilizzabile.

Quando un README è corretto ma chi arriva non capisce il prodotto, il valore nel proprio lavoro o come iniziare.

## Adattare la presentazione al tuo prodotto

Si conserva il rapporto fra identità del prodotto, lavoro del destinatario, capacità sostenuta dalle fonti e primo gesto disponibile. Cambiano settore, maturità, pubblico e forma della prova.

Porta README e istruzioni del progetto, un caso d’uso reale, installazione, stato e prove. La repository può contenere software, un metodo didattico o una ricerca; la forma segue ciò che il lettore può fare adesso.

## Primo uso

Leggi SKILL_IT.md e GUIDA_OPERATIVA_IT.md. Allega in chat l’intero AVVIO_CHAT_IT.txt e descrivi il tuo incarico. L’avvio include metodo, sapere pratico e 3 esempi sviluppati.

## File ed edizione

Edizione pubblica 0.1.0. Inglese principale, con corrispondenti file italiani. Leggi INSTALL_IT.md per l’installazione nel progetto. Il metodo si usa autonomamente o con un kernel. Esempi ed esplorazione sul sito sono illustrativi.
