# D-ND Skill Evolution Guard

Evolve an AI competence through real work

Put a correction or learning into the method that should use it next time.

Understands which relationship changed the result and updates the competence, entry point or active projection that should continue from that difference.

Use it when an error recurs, a capability improves through use or existing knowledge is not reached during work.

## Adapt the capability through your own work

Education, research, services and cultural work supply different sources and choices. Bring your purpose, an existing method or example, and the means actually available. Preserve what makes a choice useful when the situation changes.

The receiving system may be conversational, file-enabled, tool-connected or organized through an existing kernel. Use its actual entry and continuity; the library case teaches a relationship, not a required project shape or provider.

## First use

Read SKILL.md and OPERATING_GUIDE.md. Attach the whole START_CHAT_EN.txt in a chat and describe your actual assignment. The starter includes method, practical knowledge and 4 worked examples.
