# Resource Need Formation

**Understand which resources a project actually needs**

Forms the resource need from what must become possible, before selecting a provider, financial instrument or other carrier.

## When to use it

When a project asks for money, tools, people, access or time and needs to understand what would actually change the result.

## First use

We want to make this result or continuation possible: […]. Present assets and limiting conditions are […]. Help us form what resource function is needed, why, when and in what useful amount before selecting a carrier.

Use the complete starter, or make the whole folder readable. [Operating method](SKILL.md) · [Operating guide](OPERATING_GUIDE.md) · [Examples](EXAMPLES.md) · [Complete starter](START_CHAT_EN.txt) · [Install](INSTALL.md)

## The need can change how needs are formed

The direct work forms a resource function and its reason. A meta relation appears when it exposes a missing competence or a composition that changes the resource demand itself.

The method becomes its own object when the acquired resource fails to change the expected condition, or an unexpected substitute works. The reusable correction changes how later needs are recognized and quantified.

## What this edition carries

Public derivation of Resource Need Formation, a native Business Manager faculty. It transfers the function/carrier distinction, causal need, substitution, time horizons, quantity and consequence readback without private financial data or inherited procurement authority.
