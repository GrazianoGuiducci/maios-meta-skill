# Install Classify Content With Taxonomic Titles And Descriptions in Codex

This kit is version 0.3.2. Keep the whole `classify-content-with-taxonomic-titles-and-descriptions` folder together.

1. Extract the downloaded ZIP.
2. Copy `classify-content-with-taxonomic-titles-and-descriptions` into your project's `.agents/skills/` directory. The entry is `.agents/skills/classify-content-with-taxonomic-titles-and-descriptions/SKILL.md`. Preserve any existing folder rather than overwriting it.
3. Open Codex in that project and invoke `$classify-content-with-taxonomic-titles-and-descriptions` with a concrete intent and relevant sources. Restart the session if the entry does not appear.

Ask for Italian output to work in Italian; the installed entry remains English and SKILL_IT.md is available. Read OPERATING_GUIDE.md and observe first use with your actual tools.
