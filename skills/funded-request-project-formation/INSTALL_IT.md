# Installare Funded Request Project Formation

Estrai il pacchetto ZIP completo e copia la cartella funded-request-project-formation in `.agents/skills/` del progetto. Conserva una copia esistente e il suo apprendimento anziché sovrascriverla. Apri Codex nel progetto e richiama `$funded-request-project-formation` con un incarico reale. Se la discovery non è aggiornata, avvia una nuova sessione. In un altro host usa l’ingresso nativo o allega AVVIO_CHAT_IT.txt. Leggi guida pratica ed esempi insieme alla competenza.
