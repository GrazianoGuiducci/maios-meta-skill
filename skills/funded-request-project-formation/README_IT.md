# Funded Request Project Formation

Formare un progetto da una richiesta finanziata

Comprendere il cambiamento richiesto e formare capacità, soluzione e progetto che possono rispondervi.

Forma soluzioni e progetti da bandi, challenge, RFP e collaborazioni finanziate, componendo il sapere esistente e sviluppando le competenze necessarie.

Quando una richiesta esterna offre risorse e vuoi comprendere quale lavoro utile rendono possibile le tue capacità effettive.

## Primo uso

Read SKILL_IT.md and GUIDA_OPERATIVA_IT.md. Allega in chat l’intero AVVIO_CHAT_IT.txt e descrivi il tuo incarico. L’avvio include metodo, sapere pratico e tre esempi sviluppati.

## File ed edizione

Edizione pubblica 0.1.0. Inglese principale, con corrispondenti file italiani. Leggi INSTALL_IT.md per l’installazione nel progetto. Il metodo si usa autonomamente o con un kernel. Esempi ed esplorazione sul sito sono illustrativi.
