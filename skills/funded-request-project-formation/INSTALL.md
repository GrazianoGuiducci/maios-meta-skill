# Install Funded Request Project Formation

Extract the complete ZIP and copy its funded-request-project-formation folder into your project’s `.agents/skills/`. Preserve an existing copy and its learned knowledge instead of overwriting it. Open Codex in that project and invoke `$funded-request-project-formation` with a real task. If discovery has not refreshed, start a new session. For another host use its native discovery or attach START_CHAT_EN.txt. Read the practical guide and examples alongside the skill.
