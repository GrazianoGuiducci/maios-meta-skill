# Situated Possibility Formation

Scoprire e sviluppare possibilità per un progetto

Intento, capacità presenti e nuova comprensione formano il prossimo movimento utile.

Rende comprensibili possibilità utili e sviluppa domande, relazioni o mezzi che possono trasformarle in lavoro.

Quando un’idea è incompleta, la prima soluzione appare stretta o un nuovo sapere può cambiare ciò che il progetto può diventare.

## Primo uso

Leggi SKILL_IT.md e GUIDA_OPERATIVA_IT.md. Allega in chat l’intero AVVIO_CHAT_IT.txt e descrivi il tuo incarico. L’avvio include metodo, sapere pratico e 4 esempi sviluppati.

## File ed edizione

Edizione pubblica 0.1.1. Inglese principale, con corrispondenti file italiani. Leggi INSTALL_IT.md per l’installazione nel progetto. Il metodo si usa autonomamente o con un kernel. Esempi ed esplorazione sul sito sono illustrativi.
