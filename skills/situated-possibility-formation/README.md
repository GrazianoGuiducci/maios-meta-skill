# Situated Possibility Formation

Discover and develop possibilities for a project

Let intent, existing capabilities and new understanding shape a useful next movement.

Makes useful possibilities intelligible and develops the questions, relations or means that can turn them into work.

When an idea is incomplete, the first solution feels narrow, or new knowledge can change what the project could become.

## First use

Read SKILL.md and OPERATING_GUIDE.md. Attach the whole START_CHAT_EN.txt in a chat and describe your actual assignment. The starter includes method, practical knowledge and 4 worked examples.

## Files and edition

Public edition 0.1.1. English is primary; Italian counterparts are included. Read INSTALL.md for project installation. The method is usable independently or with a kernel. The examples and the website exploration are illustrative.
