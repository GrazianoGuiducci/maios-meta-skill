# Operate FDLA — application examples

[Italiano](ESEMPI_IT.md). The following cases illustrate how the method is used.

## Correct a rewrite that closes the author’s open possibility

An assistant makes prose more fluent and closes a possibility the author left open. FDLA recovers the source passage and corrects the projection. The guide preserves the relation between that editorial choice and the loss so later writing can begin differently.

## Correct a completion claim that exceeds a passing test

A check establishes that files are valid. The assistant says the whole task is complete, although the requested result includes an interaction not yet observed. Correction retains the test for what it establishes and recomposes continuation from the actual object.

## Understand what a change of representation exposes or introduces

A long account hides a responsibility relation. A map makes it visible but may also impose separations absent from the object. Return the difference to sources and consequences before using it; the new representation is not independent confirmation.
