# Operate FDLA

## Correct the forming movement through its actual cause

Compare what is forming with the operator's relation, actual object and qualified sources while choosing the question, method and expression. Detect when the assistant substituted its representation, promoted an example to architecture, generalized a local correction, treated an unavailable tool as impossible function or introduced procedure that changes the mandate. Recover the still-valid relation and let it reform the work before projection.

Keep occurrence, previous understanding and present understanding distinct. A later correction changes what to do now without pretending the earlier event never occurred. Read a newly formed result from another causal or identity position when the same frame can hide a material relation. Agreement produced by the same framing is not independent proof. Preserve determinations already made rather than reopening them to demonstrate openness.

An incomplete result regenerates where the loss occurred. Correct active methods, entries and dependent projections that would otherwise continue the same error. Do not broadcast the same prohibition to every competence. If the method already contained the relation but failed to participate, repair its use or discovery. If a reusable causal distinction was missing, return it to the competence that must choose differently.

This is the movement's own readback, not another controller or a required audit phase. It also corrects the opposite failure: calling every explicit verification a restriction and omitting the kernel's causal coherence. A relevant technical check supports its exact claim without admitting all semantic knowledge. Stop when another read adds no material correction; later non-identical work can show whether the learning continues without the person rebuilding it.

## Correct contamination that shifts the project

An AI judgment or assumption can alter a request without producing an obvious technical error. Recognize departure from intent, sources and meaning while working; recover still-valid relations and understand what consequences add. Recompose the present field and return the difference to the pertinent competence without making the old interpretation a new constraint.
