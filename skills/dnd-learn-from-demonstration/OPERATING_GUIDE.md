# D-ND Learn From Demonstration — practical operating knowledge

## Choose the source that can teach the relation

A person demonstrating, an assistant being corrected, an artifact, paired examples and a retrospective trace expose different knowledge. Combine them when their differences matter. Keep only checkpoints needed to recover the choice. A screenshot can teach hierarchy but may not reveal transition timing; narration can explain purpose without proving the behavior occurred. Preserve those complementary limits.


## Turn a correction into reusable understanding

Keep the original decision, the correction, the condition that changed and what should survive in a later different case. If a title was corrected because it hid the subject, retain subject recognition as the reason; do not turn a preference for that one title into a permanent length rule. A useful learning note can be brief if the source and rationale remain reachable.


## When implementation is the intended result

Connect observed states and exceptions to the actual domain, implementation and rendered or interaction comparison. Distinguish a proposed behavior from code written and behavior observed. The source may justify an adaptation rather than literal reproduction. Do not store unrelated private recordings or claim silent background observation. A new demonstration can revise the implementation and the learning method together.


## A listed capability is not evidence of usable access

A demonstration may fail before its method can operate because the receiving host cannot read a selected file or invoke a required tool. A catalogue entry and a requested permission mode describe conditions, not a successful operation. Preserve the actual response and determine which relation was exercised before judging the competence. A bounded adapter can supply means if it is available and entrusted; changing the adapter changes the conditions under which the recipient is observed. It does not prove the original host operation worked or authorize broader access.


## Continuation is visible in what the preserved reasons change

When evaluating a claim about native compact, preserve evidence of that event and distinguish it from an observer-written summary or a restarted conversation. A new permitted source can show whether the project guide and method remain useful: observe the sources reached, changed choices, preserved unknowns and original material. Keep local results with their owner and return the reusable evaluation lesson to the competence that learns from demonstrations. The observation concerns that recipient, task and means. It does not reveal hidden model state or establish that every later session will retain the same knowledge.

## From a demonstrated task to a competence that learns

The direct work is understanding and applying an example. A meta relation appears when the example forms or changes the competence that performs that work.

The relation is autological when a consequence corrects this learning method itself: for example, visible form was mistaken for the reason it worked. The practical competence and its generator can receive different lessons from the same event.
