# Install D-ND Learn From Demonstration

Keep the complete `dnd-learn-from-demonstration` folder together. Extract the ZIP and copy the folder into your project’s `.agents/skills/` directory. Preserve an existing copy and its learned knowledge instead of overwriting it. Open Codex in that project and invoke `$dnd-learn-from-demonstration` with a concrete task. Restart the session if the skill is not listed. Ask for Italian output when useful; the canonical entry remains English.

Read OPERATING_GUIDE.md and observe the first use with the actual project. Discovery, useful work and later learning are distinct. In another host, use its native skill discovery or attach START_CHAT_EN.txt to a chat.
