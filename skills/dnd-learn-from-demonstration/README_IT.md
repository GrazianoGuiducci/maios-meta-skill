# D-ND Learn From Demonstration

Insegnare un lavoro alla propria AI attraverso gli esempi

Trasforma dimostrazioni, spiegazioni e correzioni in un metodo che l’assistente può adattare e continuare.

Comprende le decisioni dietro un esempio e porta l’apprendimento sostenuto dalle fonti nella competenza o implementazione che deve operare diversamente.

Quando un buon risultato dipende da sapere pratico che devi spiegare ripetutamente al tuo assistente.

## Primo uso

Leggi SKILL_IT.md e GUIDA_OPERATIVA_IT.md. Allega in chat l’intero AVVIO_CHAT_IT.txt e descrivi il tuo incarico. L’avvio include metodo, sapere pratico e 4 esempi sviluppati.

## File ed edizione

Edizione pubblica 0.1.1. Inglese principale, con corrispondenti file italiani. Leggi INSTALL_IT.md per l’installazione nel progetto. Il metodo si usa autonomamente o con un kernel. Esempi ed esplorazione sul sito sono illustrativi.
