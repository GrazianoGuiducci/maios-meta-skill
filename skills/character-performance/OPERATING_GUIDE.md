# Character & Object Performance — practical operating knowledge

## Contact makes an action believable

When a hand supports a pot, the contact point, apparent weight, balance and response of both objects matter. Floating contact can contradict the intended action even when the animation is smooth. Use the scene’s material conditions and the actual asset’s possibilities. Technical collision or physics tools are means to investigate that relation, not requirements for every performance.


## Readable identity persists through change

Preserve the features that identify the character or object while its pose, view and expression vary. A tempting facial deformation can lose that identity. Observe the result and prefer a smaller meaningful gesture when reconstruction is uncertain. The actor’s narrative state and the technical state of its geometry stay connected but distinct.

## A gesture can improve the way performance is formed

A discovered relation between pause, contact and meaning can change both this scene and the method that approaches another actor.
