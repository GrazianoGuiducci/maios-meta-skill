# Kernel Continuum Awareness

Maintain coherence across an AI kernel’s capabilities

Preserve the system’s living relations through corrections, configuration changes and reentry.

Keeps operating understanding reachable and lets the kernel recognize how a difference changes its methods and relevant incarnations.

When a system grows, changes configuration or needs to recover how it operates after losing context.

## First use

Read SKILL.md and OPERATING_GUIDE.md. Attach the whole START_CHAT_EN.txt in a chat and describe your actual assignment. The starter includes method, practical knowledge and 5 worked examples.

## Files and edition

Public edition 0.3.3. English is primary; Italian counterparts are included. Read INSTALL.md for project installation. The method is usable independently or with a kernel. The examples and the website exploration are illustrative.
