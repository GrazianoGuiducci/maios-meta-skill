# Kernel Plugin Incarnation — application examples

[Italiano](ESEMPI_IT.md). The following cases illustrate how the method is used.

## Connect a research assistant’s method to an archive tool

The method explains how to qualify and connect sources; a supported tool reads the archive. Integration connects those contributions without putting credentials in the skill. A first case observes data access and method use separately.

## Repair a competence’s entry when installation already works

Real work reveals that the installed plugin’s entry does not make the useful situation recognizable. Correct discovery and the pertinent description while preserving the valid method body. Reinstallation or additional tools do not automatically address that cause.

## Correct retrieval when an index returns a superseded source

The plugin finds the right document through an index but retrieves an old version. Retrieval must reach the current source or preserve uncertainty about freshness. The case can also change the porting method: retrieval evidence must concern the source actually supporting the result.
