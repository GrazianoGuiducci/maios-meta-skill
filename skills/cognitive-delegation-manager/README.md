# Cognitive Delegation Manager

**Make several AI assistants contribute to the same work**

Connects complementary contributions through shared intent, accessible sources, concurrent ownership and a meaningful return to the project.

## When to use it

When a project uses more than one assistant or needs knowledge or tools available in another environment.

## First use

We are working on […]. Intent, sources and established decisions are […]. Assistants and tools actually available are […]. These contributions are already in progress: […]. Prepare and coordinate the useful contributions within the authorized scope.

Use the complete starter, or make the whole folder readable. [Operating method](SKILL.md) · [Operating guide](OPERATING_GUIDE.md) · [Examples](EXAMPLES.md) · [Complete starter](START_CHAT_EN.txt) · [Install](INSTALL.md)

## Collaboration can improve how collaboration is formed

Direct work composes and integrates contributions. A meta relation appears when a return changes a competence or the way assignments and sources are formed.

The relation is autological when this coordination method recognizes that its own handoff caused missing context, unnecessary serialization or a false inference of receipt. The learned difference changes the next collaboration.

## What this edition carries

Public derivation of Cognitive Delegation Manager, with intent-first handoff and receiver-preparation knowledge. It retains contribution formation, concurrency, return and reciprocal learning without importing private node identities, project state or messaging authority.
