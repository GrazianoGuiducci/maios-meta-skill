# Semantic Timelapse Formation

**MKCV — Mini Kernel Code Video** è il campo generale di competenze e produzione; **VC-30s** è un profilo di durata. Lo [Studio-Lab](VC30_STUDIO_LAB_IT.md) è disponibile come metodo, non come runtime installato.

**Generare prima un'immagine di esempio, poi costruire in codice il primo frame e un timelapse di 30 secondi.**

L'immagine A viene dal generatore; B è il primo frame codificato. L'immagine A serve per non costruire il frame «andando a memoria». A è prima nel lavoro, ma non deve raffigurare il secondo zero del film. La gestione della RAM è una questione tecnica separata.
