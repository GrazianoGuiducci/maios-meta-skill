# Semantic Timelapse Formation

**Generate an image example first, then build the first frame in editable code and form a 30-second timelapse.**

This public resource preserves the distinction between an image-generator reference (A) and the coded first frame (B). The reason to generate A first is not to build B "from memory"; buffering fewer frames in RAM is a separate technical choice.

Open [SKILL.md](SKILL.md), [OPERATING_GUIDE.md](OPERATING_GUIDE.md) and [EXAMPLES.md](EXAMPLES.md), or copy the complete [START_CHAT_EN.txt](START_CHAT_EN.txt) into a chat. Supply your sources and real tools. [Italiano](README_IT.md).
