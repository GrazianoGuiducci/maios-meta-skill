# Concept-to-Media Formation

**Turn a concept into a coherent family of media**

Forms the shared concept and editorial relation from which different media can be produced without changing the source meaning.

## When to use it

When an idea is understood but has not yet become a clear image, explanation, presentation or participatory artifact.

## First use

The concept and qualified source are […]. The receiving situation and available media or production tools are […]. Help us form the relation that should become perceptible, then prepare or produce the entrusted media and inspect the result.

Use the complete starter, or make the whole folder readable. [Operating method](SKILL.md) · [Operating guide](OPERATING_GUIDE.md) · [Examples](EXAMPLES.md) · [Complete starter](START_CHAT_EN.txt) · [Install](INSTALL.md)

## A concept can change the competence that represents concepts

The direct work forms the semantic media field and produces entrusted artifacts through pertinent means. A meta relation appears when it develops a reusable representation method or composes the capacities needed for it.

The relation is autological when a visual reveals that this method imposed a sequence, hierarchy or claim absent from the concept. Correcting the common meaning and representation changes how the next media field is formed.

## What this edition carries

Public derivation of Concept-to-Media Formation, with source-bound editorial meaning and complementary Design Kernel knowledge. The kit carries media-family formation, participatory semantics and causal learning; rendering and channel effects use the recipient's actual tools and mandate.
