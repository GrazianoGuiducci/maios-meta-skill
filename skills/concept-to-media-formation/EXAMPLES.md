# Worked examples

The following cases are illustrative. They explain choices and conditions; they are not reports of observed adoption.

## A correction changes later work

The concept is learning through an author's correction. A circular arrow suggests repeating the same action, while the source describes a changed method. The representation instead makes the original case, understood difference and later different case perceptible. The caption explains the consequence and keeps the example illustrative. The visual does not claim a change in model weights or measured general learning.

## One relation across an infographic and a presentation

A project explains how several competences contribute to one result. The infographic makes simultaneous relations visible; the presentation progressively reveals why each contribution matters. Both derive from the same semantic source. A later correction to one owner's role reaches both artifacts, while their spatial and temporal forms remain different. The family preserves meaning without copying one layout.

## A question sequence needs a real response path

A team asks for a participatory guide. The assistant understands what the reader can choose, the feedback and how responses would be used. A static social picture can invite comments, while an actual questionnaire requires a supported response mechanism and selected data handling. The prepared artifact states its real interaction. An animated control alone is not presented as collected answers or adaptive inference.
