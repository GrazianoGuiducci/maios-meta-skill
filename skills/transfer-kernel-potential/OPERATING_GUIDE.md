# Transfer Kernel Potential — practical operating knowledge

## Meaning and mechanism travel together when needed

A method can operate semantically in a conversation before persistent files are created. Persistence, execution and an account action require actual mechanisms. A package with correct blobs can still leave its starter without decisive knowledge. Conversely, different file shapes can faithfully preserve the same function. Qualify the exact contract rather than treating one technical form as the kernel's ontology.


## Recover earlier work without replaying it

Use the living guide to recover source reasons, open contributions and differences still pending. Keep temporal node state with its owner. Historical cases can teach the current transfer without making their next steps today's instructions. When a receiver reconstructed a missing route successfully, preserve that contribution and repair the route if it is still needed; recovery alone does not complete the original delivery.


## A generative recipient continues from work

A seed must support actual initial context, useful first work, acquisition of missing knowledge, formation of pertinent competences and return of consequences. Do not require a person to design a skill catalogue before starting. A compiler or previously released package is an implementation, rather than the maximum inheritance possible. Improve the receiving source that should use the knowledge normally, without waiting for every neighboring generator to change.


## Compare the work made possible, not the resemblance of carriers

A library receives a workshop method from another library. It already has a practice for multilingual groups and cannot store participant information in the same place. Read those choices and their reasons before deciding what to import. Preserve the portable relation between an interpretation and the next question; replace a source-specific worksheet or private storage path with the receiving means. A conversational system can return a complete guide to save. A file-enabled system can retain it in the existing project. Neither form is a universal requirement or proof that a scheduler or account is configured.


## A partial update preserves earlier learning and open contributions

A source update can add a way to compare interpretations without replacing the recipient’s multilingual practice or an earlier unresolved accessibility contribution. Integrate the affected relation where the recipient actually reads it: method, guide, starter or tool input. Preserve the earlier evidence at its original identity. Read back from the recipient when its experience changes what the source should teach. If a useful method already exists but its entry is narrow, repair that entry instead of creating a second competence or changing a neighboring compiler.

## Transfer can evolve the capability that transfers

The object is itself a competence or kernel, giving the work a meta relation. The recipient receives the ability to understand and continue, alongside the selected operating functions.

The relation is autological when a source or recipient reveals that this method's question or selection criterion narrowed what could travel. The reusable correction changes the transfer method and its entry; it does not require automatic mutation of every source.
