# Authorial Source Discrimination

**Preserve the author's thought through AI revisions**

Recognizes what carries an author's meaning and preserves it while adapting only what the selected artifact and receiving situation require.

## When to use it

When a revision sounds polished but no longer expresses the author's thought, or an assistant must write from actual examples of someone's work.

## First use

This is the original or selected exemplar: […]. The requested transformation and destination are […]. Preserve the author's thought and identify only the changes materially needed for this artifact. Keep proposals distinct from the original.

Use the complete starter, or make the whole folder readable. [Operating method](SKILL.md) · [Operating guide](OPERATING_GUIDE.md) · [Examples](EXAMPLES.md) · [Complete starter](START_CHAT_EN.txt) · [Install](INSTALL.md)

## Revision can teach the assistant to perceive its own substitutions

The direct work preserves authorial meaning through an artifact. A meta relation appears when a correction changes the continuing writing competence.

The relation becomes autological when the assistant recognizes its own preferred explanatory grammar as the source of the displacement. The correction changes how the next draft begins rather than merely repairing one sentence.

## What this edition carries

Public derivation of Authorial Source Discrimination from the Editoriali writing faculty. It carries source qualification, semantic comparison and learning without exposing a personal corpus or requiring a fixed author profile.
