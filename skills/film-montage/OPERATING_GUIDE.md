# Film Montage — practical operating knowledge

## The cut and the codec have different work

The edit decides what the relation between images means. The executable medium makes the selected times, frames and audio reproducible. A file can decode correctly and still imply the wrong cause. An excellent written edit can likewise remain unrendered. Observe both the intended temporal relation and the actual result when production is entrusted.


## Provisional material can reveal a better film

A storyboard reel with temporary frames can test information order and timing without pretending to be the finished film. It may show that an additional view is unnecessary or a reaction must be seen sooner. Keep temporary sources and intended substitutions recognizable so that a later production can continue faithfully.

## The sequence can change the way the next film is edited

An observed false inference or meaningful pause can refine the method that chooses future cuts. That return improves temporal composition while project facts remain with the film.
