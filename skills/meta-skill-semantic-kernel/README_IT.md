# Meta_Skill Semantic Kernel

Creare e comporre competenze per un sistema AI

Meta_Skill fa diventare sapere, esperienza e possibilità capacità utilizzabili e capaci di evolvere.

Riconosce le capacità pertinenti, riusa o compone quelle presenti e forma il sapere operativo necessario a una nuova competenza quando emerge quella relazione.

Quando un sistema deve sviluppare un saper fare duraturo e la sola istruzione per il task non ne conserva metodo e apprendimento.

## Adattare la capacità attraverso il proprio lavoro

Educazione, ricerca, servizi e lavoro culturale portano sorgenti e scelte diverse. Porta intento, metodo o esempio esistente e mezzi realmente disponibili. Conserva ciò che rende utile una scelta quando la situazione cambia.

Il sistema ricevente può essere conversazionale, avere accesso ai file o a strumenti, oppure operare attraverso un kernel esistente. Usa ingresso e continuità reali; il caso della biblioteca insegna una relazione, non una forma obbligatoria di progetto o un provider.

## Primo uso

Read SKILL_IT.md and GUIDA_OPERATIVA_IT.md. Allega in chat l’intero AVVIO_CHAT_IT.txt e descrivi il tuo incarico. L’avvio include metodo, sapere pratico e 4 esempi sviluppati.
