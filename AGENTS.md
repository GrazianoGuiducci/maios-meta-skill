# Working on MAIOS Meta-Skill

This repository owns the public competences, use guides, examples and catalogue.
Start from README.md, CURRENT_STATE.md and the selected resource's SKILL.md.

Preserve the useful capacity when making a resource public. Remove private
identities, credentials, controller state and internal paths while retaining
the knowledge a recipient needs to perform and continue the work.

The operator's context and sources lead the work. Keep original contributions
separate from AI proposals. Titles identify the object; subtitles explain its
use to a reader who has not seen the conversation.

Each resource has its own identity and version. When it changes, align its
guide, starter, catalogue, presentation and downloadable package as needed.
Use tools/build_release.py to build the selected package reproducibly.

Publishing files does not prove a skill is installed, discovered or exercised
in another environment. Examples do not confer access to accounts, permission
to contact people or authority over another activity.

Keep meaningful findings and the next movement in the selected resource's
guide or in CURRENT_STATE.md. Respect valid concurrent work. Do not copy a
private source tree or install this collection into a user's environment
merely because you are editing this repository.
